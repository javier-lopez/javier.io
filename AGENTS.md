# Working in this repo

A Jekyll blog, built and served entirely through Docker. The rules live in
`.agents/`, one file per subject. Claude Code expands the imports below; other
tools read this as a list and should open the files themselves.

@.agents/documentation.md — what belongs in README.md, and in a comment
@.agents/dev-server.md — ports, and the files the container writes
@.agents/jekyll.md — what the build publishes and what it must not
